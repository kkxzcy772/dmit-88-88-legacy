## 几个容易被忽略的细节

**流量是双向计算的**，上传加下载一起算进月额度。1TB 听起来不少，跑持续上传或大流量代理会消耗得比想象中快。

**流量跑完不会停机**，会按套餐档次限速到 4Mbps 到 10Mbps 不等，然后不限量继续用。这条对长期跑服务的用户比「给多少流量」更重要。

**折扣大多是循环折扣**，也就是续费时依然有效，不是首年优惠。DMIT 的常规玩法是把折扣和产品线、计费周期绑定，比如某些系列年付自动带折扣，部分优惠码需要在结算页点 Validate Code 验证后才生效。优惠码更新很频繁，也有有效期，与其记住某个字符串，不如在下单前把当前官网列出的活动看一遍。

**支付方式对国内用户友好**，支持 PayPal、支付宝、信用卡，也有微信支付。

**IP 被墙的处理**，社群讨论里常被提到的一点是可以定期免费换 IP，具体周期和政策建议下单前直接问客服确认，不同时期的说明并不完全一致。

## 常见问题

**$88.88 这个价格以后还会回来吗？**
大概率不会以同样形式回来。AN4 是硬件资源耗尽的自然退场，不是临时活动结束。除非 DMIT 再放一批限量特价，否则这个数字会留在历史帖子里。

**现在买 AN5 是不是接盘？**
看你缺什么。AN5 的硬件对于绝大多数个人用途是过剩的，如果你真正的需求是 CN2 GIA 回程，那多付的部分并没有换来对应的体验提升。但如果你跑的是计算密集或 IO 敏感的业务，9005 平台的提升是实打实的。

**安不安全，会不会跑路？**
DMIT 从 2017 年前后运营至今，同时是搬瓦工的核心上游供应商之一，机房和线路资源在同行里属于上游位置。这不能替代你自己的风险评估，但它确实不是新冒出来的小商家。

**该月付还是年付？**
入门款月付价格不便宜，年付的单价明显更低。但如果这是你第一次用 DMIT，先用月付或季付跑一个完整周期，特别是要过一遍晚高峰，再决定要不要锁年付，比为了省几十美元直接押一年更稳妥。
